圖片格式轉換器 v1.3.0 — 發布驗收紀錄
紀錄日期：2026-11-09
GitHub Release：`https://github.com/1NotAmon/windows-image-format-converter/releases/tag/v1.3.0`

候選內容
- 白底黑字與黑色主要按鈕；按鈕、設定欄位與圖片清單外框加入圓角。
- 匯入時將輸入路徑正規化為完整路徑，再依 Windows 不區分大小寫規則去重。
- JPEG 編碼參數與 GDI+ 圖像資源在成功或例外路徑均會清理。
- 提供 x64 GUI EXE、可攜 ZIP、來源碼 ZIP，以及繁體中文單檔 Inno Setup 安裝程式。
- Setup 安裝至目前使用者，不需系統管理員權限；建立開始功能表捷徑，桌面捷徑可選。右鍵整合預設未勾選；若勾選會取代本專案舊版本登錄，解除安裝會移除該登錄而不還原舊版本。
- 保留 v1.2.0 的單一視窗、轉檔格式、原圖／既有輸出保護及目前使用者右鍵選單機制。

本機驗收（Windows 10 Home 22H2／Windows PowerShell 5.1）
- 專案 PowerShell 腳本：UTF-8 BOM 與語法解析通過。
- 250 張 JPG/JFIF 實際匯入；重複路徑及相對路徑別名不增加清單列。
- 9 種輸入副檔名 × 5 種輸出格式，共 45 組轉檔後重新開啟核對格式／尺寸通過。
- 100 張批次轉檔、透明 PNG、JPEG 白底與品質、巢狀資料夾、既有輸出不覆寫、同資料夾轉檔保護原圖及損毀檔隔離通過。
- 30 次連續 JPEG 轉換後來源圖片可正常移動，資源釋放回歸通過。
- v1.3.0 x64 EXE 版本資訊 `1.3.0.0`；三次近乎同時啟動合併至一個 GUI，三張圖片均載入並正常關閉，PackageTest 通過。
- 右鍵安裝／移除靜態回歸與本機往返測試通過：先備份既有 HKCU 項目，確認 v1.3.0 EXE、`%1` 與多選模式，再移除該 verb，最後匯入備份並逐位元核對原登錄值已還原；測試後系統設定沒有淨變更。
- Inno Setup 7.1.1 成功建置繁體中文單檔 Setup，FileVersion `1.3.0.0`；隔離臨時路徑安裝／解除安裝、開始功能表捷徑、Apps and Features 卸載項測試通過。測試明確關閉右鍵任務，確認現有右鍵登錄未改變。
- 白黑圓角介面以實際 Windows Forms 視窗載入三張臨時圖片目視檢查。
- Microsoft Defender 即時防護已開啟、病毒碼 `1.463.203.0`（age 0）；對最終重建後的 v1.3.0 候選資料夾（含 Setup、EXE、兩個 ZIP 與校驗檔）完成自訂掃描，該目錄威脅偵測數為 0。這不等於 SmartScreen 信譽或簽章驗證。

# v1.0.0 來源碼候選版

**狀態：候選資料，尚未正式發布。** 已發布的 v0.1.0 保持原樣，本資料夾不會取代它。

`source/` 是目前開發主線來源碼的快照，供 v1.0.0 驗收與比對使用；快照中的 `VERSION` 仍標示 `0.1.0`，不代表它已是正式 1.0.0。來源碼包只有在完成下列項目後才會正式標為 v1.0.0：

- 25 張混合 JPG/JFIF 匯入及重複路徑去重回歸測試。
- PNG、JPEG、BMP、GIF、TIFF 實際轉換後重新開啟驗證。
- 巢狀資料夾、同名輸出不覆寫及損毀圖片錯誤處理。
- Windows 10 與 Windows 11 人工介面驗收，以及 GitHub Actions 測試通過。

目前新增檔案總管右鍵選單選項，可多選圖片並自動載入清單；安裝器只修改目前使用者登錄檔，並提供移除腳本。25 張匯入回歸、右鍵多路徑啟動及影像編碼器 smoke test 已在本機通過。完整 GUI 轉檔矩陣、大批次及乾淨 Windows 10/11 驗收仍待完成。正式版本仍需更新版號與變更紀錄；本候選包不會建立或取代 GitHub Release。

# v1.0.0 來源碼候選版

**狀態：候選資料，尚未正式發布。** 已發布的 v0.1.0 保持原樣，本資料夾不會取代它。

`source/` 是目前專案來源碼的快照，供 v1.0.0 驗收與比對使用；快照中的 `VERSION` 仍標示 `0.1.0`，不會假稱它已是正式 1.0.0。來源碼包只有在完成下列項目後才會正式標為 v1.0.0：

- 25 張混合 JPG/JFIF 匯入及去重回歸測試。
- PNG、JPEG、BMP、GIF、TIFF 實際轉換後重新開啟驗證。
- 巢狀資料夾、重複路徑、同名輸出不覆寫及損毀圖片錯誤處理。
- Windows 10 與 Windows 11 人工介面驗收，以及 GitHub Actions 測試通過。

本機已通過 25 張匯入數量測試及影像編碼器 smoke test；完整 GUI 轉換矩陣與 Windows 11 人工測試仍待驗收。正式版本仍需更新版號與變更紀錄，並由使用者確認後才建立 GitHub Release。

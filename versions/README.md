# 版本資料夾

此資料夾依版本整理來源碼快照與 Windows 下載成品。根目錄仍是目前唯一的開發主線；版本資料夾是可下載快照，不取代或搬走根目錄原始碼。

- `v1.0.0/`：PowerShell/Windows Forms 來源碼候選快照，保留歷史驗收記錄；尚未建立正式 GitHub Release。
- `v1.1.0/`：舊版 EXE 打包候選包，已由 v1.2.0 單視窗修正版發布包取代；v1.2.0 尚未同步至 GitHub，保留舊檔供追溯但不建議新下載者使用。
- `v1.2.0/`：本機已準備的正式發布包，包含來源碼 ZIP、x64 EXE、可攜式 EXE ZIP、右鍵選單工具、Release notes 及 SHA-256 校驗碼。GitHub 同步逾時，尚未建立正式 tag／Release；線上仍只有 v0.1.0。已完成的本機測試與未驗收項目詳見 Release notes。

根目錄本機 `VERSION` 為 `1.2.0`，目前是發布準備版本；GitHub `main` 尚未更新。既有 `v0.1.0` 標籤與 Release 保持原樣，未發布的 `v1.0.0` 與 `v1.1.0` 候選快照也未更動。

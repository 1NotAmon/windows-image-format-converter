# 版本資料夾

此資料夾依版本整理來源碼快照與 Windows 下載成品。根目錄仍是目前唯一的開發主線；版本資料夾是可下載快照，不取代或搬走根目錄原始碼。

- `v1.0.0/`：PowerShell/Windows Forms 來源碼候選快照，保留歷史驗收記錄；尚未建立正式 GitHub Release。
- `v1.1.0/`：舊版 EXE 打包候選包，已由 v1.2.0 單視窗修正版候選取代；保留供追溯，不建議新下載者使用。
- `v1.2.0/`：最新公開候選更新，包含來源碼 ZIP、x64 EXE、可攜式 EXE 套件 ZIP、右鍵選單工具及 SHA-256 校驗碼。此為候選版，尚未完成完整正式發布驗收，也尚未建立 tag 或 Release。

根目錄 `VERSION` 仍為 `0.1.0`，因 v1.0／v1.1 的正式驗收條件尚未全部完成；這不會更動已發布的 `v0.1.0` 標籤或 Release。完成測試並確認後，才會建立正式版本標籤與 Release。

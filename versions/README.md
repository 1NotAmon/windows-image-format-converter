# 版本資料夾

此資料夾依版本整理來源碼快照與 Windows 下載成品。根目錄仍是目前唯一的開發主線；版本資料夾是可下載快照，不取代或搬走根目錄原始碼。

- `v1.0.0/`：PowerShell/Windows Forms 來源碼候選版，包含可選的檔案總管右鍵選單整合與多張圖片共用單一視窗。尚未建立正式 GitHub Release。
- `v1.1.0/`：EXE 打包候選版，包含 x64 GUI 執行檔、右鍵選單安裝／移除工具、多啟動合併和必要授權說明。尚未建立正式 GitHub Release。

已發布的 `v0.1.0` 標籤與 Release 保持不變。只有完成各版驗收並確認後，才會把候選資料夾改為正式下載版本。
